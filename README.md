# crypto-macro-dashboard

Dashboard local macroéconomique et crypto pour aider à interpréter les signaux d'un bot Freqtrade / Hyperliquid.

## Objectif

Créer un dashboard local accessible sur :

```text
http://localhost:9070
```

## Installation
`.env`
```text
FRED_API_KEY=
COINGECKO_API_KEY=
```

## Lancer le collector
`docker compose run --rm collector`
